## What Users Love

### Universally Praised

| Theme | Platforms |
|---|---|
| All-in-one consolidation (replace 5-15 tools) | GHL, Kajabi, Kartra, Systeme.io, ClickFunnels |
| Zero or low transaction fees | Systeme.io, Kartra, Skool, GHL, ClickFunnels |
| Built-in affiliate management | Kajabi, Kartra, Systeme.io, ClickFunnels, Teachable |

### Platform-Specific Standouts

| Platform | What Users Rave About |
|---|---|
| **Kajabi** | Polished course/student experience, native Wistia video, 24/7 live chat, coach ecosystem credibility |
| **Systeme.io** | Unbeatable free tier, "it just works" simplicity, founder responsiveness, zero fees |
| **GHL** | Workflow automation engine (best-in-class for price), active community (~100K), rapid feature dev |
| **Skool** | Engagement rates "dramatically higher than FB Groups", gamification, clean UI, mobile app |
| **Teachable** | Best student UX, teachable:pay tax handling, native mobile apps, low learning curve |
| **ClickFunnels** | Funnel/checkout design, Share Funnels, Brunson training ecosystem |
| **Kartra** | Behavioral automation (IF/THEN), video hosting with CTAs, built-in helpdesks + webinars |
| **WordPress** | Maximum flexibility, best SEO, full data ownership |

## What Users Hate

### Recurring Across Platforms

| Theme | Affected |
|---|---|
| Vendor lock-in / no portable export | ALL platforms |
| Email deliverability on shared IPs | Systeme.io, ClickFunnels, Kartra, GHL |
| Page builder slow/laggy | Kartra, ClickFunnels, GHL, Systeme.io |
| Support response times | Kartra (ticket-only), Systeme.io (email-only), ClickFunnels (long waits) |

### Platform-Specific Pain Points

| Platform | Top Complaints |
|---|---|
| **GHL** | Steep learning curve, "master of none", UI changes frequently, hidden SMS/email costs |
| **Kajabi** | High price ($143+/mo), no A/B testing, 2,500 contact cap on Basic, processor surcharge |
| **ClickFunnels** | $297/mo Pro required, CF 2.0 migration pain, weak email deliverability, overhyped marketing |
| **Kartra** | "2018-era" UI, ticket-only support, cancellation friction, bandwidth limits, slow innovation |
| **Systeme.io** | No quizzes/certificates, limited integrations, no mobile app, email-only support |
| **Skool** | No landing pages, no email, can't sell products, no custom domain, affiliate bias in reviews |
| **Teachable** | 7.5% Starter fee, no marketing tools, need external tools, student import limits |
| **WordPress** | "Plugin hell", maintenance burden, security responsibility, ecosystem drama |
