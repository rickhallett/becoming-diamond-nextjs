## Core Features

### Course Builder — 6/10

- Module-and-lesson hierarchy with drag-and-drop ordering
- Content types: video, text, PDF, embedded content
- **Video hosting:** Built-in (upload directly) or embed from YouTube/Vimeo/Wistia. Basic player — no playback speed, no chapters.
- **Drip content:** Yes. Schedule by days after enrollment. Works for 30-day daily unlock.
- **Progress tracking:** Completion percentage, admin visibility, student marks complete.
- **Certificates:** No native builder
- **Quizzes:** No native engine (workaround: embed Typeform/Google Forms)
- **Community:** Discussion forums attachable to courses (Startup+)
- **Mobile:** Responsive web only, no native app

### Landing Page Builder — 6/10

- Drag-and-drop block editor, 50-70+ templates
- A/B testing on Startup+ plans
- Custom code injection, popups
- Systeme.io branding on Free plan (removed on paid)

### Lead Capture & CRM — 6/10

- Opt-in forms, central contact database with tags
- **Unlimited email sends on ALL plans**
- Visual workflow builder for automations
- No lead scoring, no pipeline, lightweight CRM
- Deliverability: moderate (shared IPs)

### E-Commerce — 7/10

- Digital downloads, courses, memberships, coaching packages
- Stripe + PayPal only
- One-click upsells/downsells, order bumps, coupons
- Built-in affiliate management
- **0% transaction fees** — major differentiator

## Migration Assessment

- **Time-to-Live:** 3-5 business days total (account + domain + landing + emails + book funnel + course + video upload)
- **Exit Strategy:** Contacts exportable (CSV). Funnels/pages NOT exportable. **Lock-in risk: Moderate.**
