!!! info "Quick Take"
    All-in-one marketing platform built for **agencies**. Powerful CRM and workflow automation, but the course builder is adequate (6/10), not exceptional. Steep learning curve (7/10) for non-technical users.

## Core Features

### Course Builder — 6/10 { .course-rating }

- Courses built inside "Memberships" or "Communities" section
- Structure: Course > Modules > Lessons
- Each lesson supports text, video, images, file downloads, assessments
- **Video hosting:** Native (upload directly). External embeds also supported. Basic player — no heatmaps or engagement analytics.
- **Drip content:** Yes. Schedule by enrollment date or calendar dates.
- **Progress tracking:** Yes. Student progress bar + admin dashboard per-student.
- **Certificates:** Yes. Auto-generated, customizable, issued on completion.
- **Quizzes:** Multiple choice, true/false, short answer. Can gate progression. Basic analytics.
- **Student experience:** Brandable member portal, custom domain. Clean but not as polished as Teachable or Kajabi. No mobile app for students.

### Landing Page Builder — 7/10

- Visual drag-and-drop (row/column layout)
- Hundreds of pre-built templates by industry
- "Snapshot" marketplace for importing entire pre-built funnels
- Mobile-responsive with mobile editing view
- Custom domains with auto SSL
- Built-in A/B split testing
- Occasionally sluggish on complex pages

### Lead Capture & CRM — 8/10

!!! success "GHL's Strongest Feature"
    The workflow automation engine is best-in-class for the price tier: if/else branching, wait steps, triggers on nearly anything, webhook support, custom JS actions.

- Drag-and-drop form builder with custom fields, multi-step forms, surveys
- Full email marketing: visual builder + HTML, templates, broadcasts, drip sequences
- Tags + custom fields for segmentation, lead scoring
- Visual Kanban pipeline for deals/leads

### E-Commerce — 7/10

- Digital products: ebooks, courses, memberships
- One-time, recurring, and payment plan options
- One-click upsells, order bumps, downsells
- **Payment processors:** Stripe, PayPal, HighLevel Payments, Square, NMI
- Promo codes (percentage or fixed)
- Built-in affiliate management

## Migration Assessment

- **Custom Domain:** CNAME/A record to GHL servers, SSL auto-provisioned. 15-60 min propagation.
- **Content Import:** No automated import. Contacts via CSV. Course content manually re-created. Pages rebuilt.
- **Time-to-Live:** ~18-34 hours / 1-3 weeks at a few hours/day
- **Exit Strategy:** Contacts exportable (CSV). Pages, funnels, courses NOT portable. Domain re-pointable. **Exit difficulty: Moderate.**
