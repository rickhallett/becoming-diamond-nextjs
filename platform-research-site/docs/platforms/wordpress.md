!!! danger "DO NOT USE — Included as Baseline Only"
    For a coach wanting independence from engineers, WordPress goes in the wrong direction. The "plugin hell" maintenance tax, security responsibility, and 40-80 hour setup cost all directly contradict the stated objectives.

**Evaluated stack:** WordPress + Elementor Pro + WooCommerce + LearnDash + FluentCRM

## Core Features

### Course Builder (LearnDash) — 9/10

!!! success "Best Course Builder in the Comparison"
    LearnDash is used by Fortune 500 companies and universities. 8 quiz types, question banks, SCORM/xAPI, granular progress tracking, Focus Mode.

- But: **No built-in video hosting** — need Bunny Stream, Vimeo, or Presto Player
- Requires WordPress expertise to configure and maintain

### Landing Page Builder (Elementor Pro) — 9/10

- 300+ templates, 100+ widgets, true visual drag-and-drop
- Popup builder, theme builder, WooCommerce builder
- Can produce heavy HTML if not managed carefully

### Lead Capture & CRM (FluentCRM) — 7/10

- Self-hosted email marketing + CRM
- Visual automation builder, zero per-email cost via SMTP
- Requires SMTP setup (technical), deliverability is YOUR responsibility

### E-Commerce (WooCommerce) — 7/10

- Overkill for a coaching business selling 1-3 products
- Free core, hundreds of gateways, subscriptions extension ($199/yr)

## The Fundamental Problem

!!! danger "Contradicts Client Goals"
    | What You Want | What WordPress Delivers |
    |---|---|
    | Independence from engineers | Requires an engineer (different stack, same problem) |
    | Low maintenance | 3-5 hrs/month minimum (updates, security, conflicts) |
    | Quick setup | 40-80 hours for experienced developer |
    | Simple operations | Plugin conflicts, security scanning, database optimization |

**Learning Curve: 9/10** (hardest in the entire comparison).

## Maintenance Burden (3-5 hrs/month minimum)

- WordPress core updates: monthly (15-30 min)
- Plugin updates (8+ plugins): weekly (30-60 min with testing)
- Security monitoring: weekly (15-30 min)
- Database optimization: monthly (15-30 min)
- Plugin conflict resolution: as needed (1-4 hours per incident)
- Backup verification: monthly (15 min)

## Sentiment

- "Plugin hell" is the #1 complaint in 2025-2026
- Solopreneurs migrating AWAY from WordPress toward managed SaaS
- WordPress.org vs WP Engine legal disputes added ecosystem uncertainty
- WordPress fatigue is real and widespread

## Migration Assessment

- **Initial Setup:** 56-104 hours. At $100-150/hr: $5,600-$15,600 developer cost.
- **Ongoing:** $100-300/mo outsourced or 3-5 hrs/mo self-managed.
- **Exit:** Full data ownership and portability is the one genuine advantage.
