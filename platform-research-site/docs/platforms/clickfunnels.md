## Core Features

### Course Builder — 6/10

- Modules > Lessons > Sections structure
- **Video:** Upload directly or embed from Vimeo/YouTube/Wistia
- **Drip content:** Yes, schedule relative to enrollment
- **Progress tracking:** Basic (student marks complete, progress bar)
- **Certificates:** Limited/unclear if native
- **Quizzes:** Basic surveys only, no question banks or grading
- **Community:** No native community feature
- **Mobile:** Responsive web only, no student app

### Landing Page Builder — 8/10

!!! success "ClickFunnels' Strongest Feature"
    The entire platform is organized around high-converting funnel pages.

- Modern drag-and-drop editor (CF 2.0 rewrite)
- 100+ funnel templates by use case
- A/B split testing built-in
- Custom HTML/CSS/JS injection
- Pop-ups and sticky bars with triggers

### Lead Capture & CRM — 5/10

- Opt-in forms: excellent (core strength)
- Email: built-in broadcasts + sequences, but **deliverability is weak** (shared infrastructure)
- Basic CRM: contact profiles with tags, not a full pipeline
- No lead scoring, limited SMS

### E-Commerce — 7/10

- **Checkout pages:** Core competency, high-converting templates
- Order bumps, one-click upsells/downsells
- Stripe and PayPal native
- Backpack affiliates (Pro+)
- Coupons and recurring billing
