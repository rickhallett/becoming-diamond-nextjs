## Core Features

### Course Builder — 7/10

- "Kartra Memberships" — purpose-built for structured courses
- **Kartra Video:** Built-in hosting with customizable player, CTAs inside video, email opt-in overlays, analytics (play rate, watch time, drop-off)
- **Drip content:** By days-after-enrollment, specific dates, or prior completion. Perfect for 30-day program.
- **Progress tracking:** Member-facing progress bar + admin dashboard
- **Quizzes:** Via Kartra Surveys & Quizzes, integrates with memberships
- **Certificates:** Not confirmed native, workaround via automation
- **Community:** Basic only, no native forum
- **Mobile:** Responsive web only, no native app

### Landing Page Builder — 6.5/10

- 500+ templates, drag-and-drop section-based
- A/B testing with statistical significance tracking
- Pop-ups (exit-intent, timed, scroll-trigger), countdown timers
- Templates feel dated vs modern tools, editor can be sluggish

### Lead Capture & CRM — 8/10

!!! success "Crown Jewel: Behavioral Automation"
    IF/THEN builder triggers on page visits, video watch %, email opens, purchases, tags, membership progress. Very powerful for nurture sequences.

- Full email marketing (broadcasts, sequences, behavioral triggers)
- Built-in lead scoring
- Tag + list segmentation, auto-tagging
- Built-in SMS (US/Canada, Twilio for international)
- Basic CRM pipeline view

### E-Commerce — 8/10

- Stripe, PayPal, Authorize.net, Braintree
- One-click upsells, order bumps, post-purchase upsells
- Book-to-course upsell flow is exactly what Kartra was designed for
- Built-in affiliate management (multi-tier commissions)
- 0% transaction fees

!!! success "Common Praise"
    All-in-one value, powerful automation, built-in video hosting, good for coaches, checkout+membership integration.

!!! failure "Common Complaints"
    UI feels "2018-era", page builder slow, ticket-only support (slow), steep learning curve, vendor lock-in, price increases, cancellation friction.

## Migration Assessment

- **Time-to-Live:** With Marketplace template: basic funnel 1-3 days. Full 30-day course: 1-2 weeks.
- **Exit Strategy:** **Biggest weakness.** Pages, funnels, memberships NOT portable. Contacts exportable (CSV). Everything else rebuilt from scratch.
