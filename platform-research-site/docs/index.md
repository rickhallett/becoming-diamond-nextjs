## The Recommendation

<div class="rec-grid" markdown>

<div class="rec-card best-fit" markdown>
<span class="rec-badge best-fit">Best Fit</span>

### Kajabi — $143/mo

<span class="score">7.20</span>
<span class="score-label">Weighted Score</span>

Course builder **8/10**. Native video hosting (Wistia). iOS/Android student app. Unlimited emails. 24/7 live chat support. No external tools needed.

[Full recommendation :material-arrow-right:](analysis/recommendation.md)
</div>

<div class="rec-card runner-up" markdown>
<span class="rec-badge runner-up">Runner Up</span>

### Kartra — $99/mo

<span class="score">6.45</span>
<span class="score-label">Weighted Score</span>

All-in-one at lower price. Best behavioral automation. Built-in video hosting with CTAs. Dated UI and ticket-only support are the trade-offs.

[View profile :material-arrow-right:](platforms/kartra.md)
</div>

<div class="rec-card budget" markdown>
<span class="rec-badge budget">Budget Option</span>

### Systeme.io — $19/mo

<span class="score">7.10</span>
<span class="score-label">Weighted Score</span>

Unbeatable value. 0% transaction fees. 3/10 learning curve. Missing quizzes, certificates, and advanced course features. Great "prove the concept" option.
